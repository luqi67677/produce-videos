# 真实成片案例

这三个案例用于证明 Produce Videos 能处理不同类型的横屏讲解与宣传内容。仓库只保留经过公开授权的压缩预览，不包含工程源素材、私人路径、声音模型或账号信息。

| 案例 | 重点 | 预览 |
|---|---|---|
| Obsidian 持续进化 AI 大脑 | 软件讲解、截图证据、信息结构与动态排版 | [视频](videos/obsidian-ai-brain.mp4) · [封面图](thumbnails/obsidian-ai-brain.jpg) |
| 不用视频模型的视频 Skill | 开源工具介绍、流程演示与代码动画 | [视频](videos/video-skill-v1.mp4) · [封面图](thumbnails/video-skill-v1.jpg) |
| ICP 与网安备案 | 长流程科普、步骤拆解、界面隐私处理 | [视频](videos/icp-filing-explainer.mp4) · [封面图](thumbnails/icp-filing-explainer.jpg) |

文件哈希、规格和发布授权记录在 `manifest.json`。安装包默认不携带案例视频，以免把 14 MB 预览复制到每个 Agent 的 Skill 目录；GitHub 仓库和 Release 页面可直接查看。
