# 真实成片案例

这三个案例用于展示 Produce Videos 面对不同内容时的实际输出。点击封面即可查看压缩视频预览。

| 案例与视频 | 这个案例展示了什么 |
|---|---|---|
| [![Obsidian 持续进化 AI 大脑](thumbnails/obsidian-ai-brain.jpg)](https://github.com/luqi67677/produce-videos/blob/main/examples/videos/obsidian-ai-brain.mp4)<br>**Obsidian 持续进化 AI 大脑** | 软件讲解如何把真实截图作为证据，再用结构化排版、代码动画和字幕维持信息节奏。 |
| [![不用视频模型的视频 Skill](thumbnails/video-skill-v1.jpg)](https://github.com/luqi67677/produce-videos/blob/main/examples/videos/video-skill-v1.mp4)<br>**不用视频模型的视频 Skill** | 开源工具介绍如何建立问题、方案和使用流程，并在没有视频生成模型的情况下完成动态表达。 |
| [![ICP 与网安备案](thumbnails/icp-filing-explainer.jpg)](https://github.com/luqi67677/produce-videos/blob/main/examples/videos/icp-filing-explainer.mp4)<br>**ICP 与网安备案** | 长流程科普如何拆解步骤、使用真实界面素材、处理隐私，并让前后镜头保持因果连续。 |

仓库只保留经过公开授权的压缩预览，不包含工程源素材、私人路径、声音模型或 API 凭证。文件哈希、规格和发布授权记录在 [manifest.json](manifest.json)。安装包默认不携带案例视频，避免把约 14 MB 的预览重复复制到每个 Agent 的 Skill 目录。
