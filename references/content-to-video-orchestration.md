# 资料到镜头级动态视频编排

## 输出边界

文档、讲稿、PPT/PDF、截图、图片或录屏是事实和素材来源，不直接等于视频画面。PPT/PDF 只提取标题、图表、图片和结构，不整页静态播放。

完整制作至少产生：brief、主张账本、叙事契约、完整口播、真实素材清单、原始素材审片计划、视觉候选与唯一主题、需要时的创作记忆和人物档案、声音选择和预检、旁白契约、镜头就绪表、需要剪辑时的 EDL、平台遮挡审查图、全量静态分镜、代表性微样片、完整低清预览、正式视频、独立 3:4 封面、审批账本、QA 和联系表。

## 画幅与时长

- `portrait`：3:4、1080×1440、30fps。
- `landscape`：16:9、1920×1080、30fps。
- 用户明确时长优先；没有时长时按平台、内容密度和观看场景推断，只有会显著改变成本或叙事时才追问。
- 超过合理上限时压缩主线或拆条，不提高到不自然语速，也不切掉换气和字头。
- 每条成片另交付 1080×1440 独立封面，横屏视频也按 3:4 重新构图。

## 风险模式

| 模式 | 判断 | 额外处理 |
|---|---|---|
| `fast` | 通常不超过 30 秒、事实稳定、无反复生成人物、无敏感录屏或授权疑点、成熟运动语法 | 合并内容/素材/风格；完整低清预览承担动态证明 |
| `standard` | 普通宣传、教程、混合素材或需要 TTS | 低风险原素材与分镜合并；完整预览前先做 4—8 秒微样片 |
| `high-risk` | 反复人物、隐私或授权风险、强事实主张、超过 90 秒、新运动语法、下载安装 | 先审身份锚点/风险原素材，再单独确认 4—8 秒样片 |

模式只控制用户中断次数，不降低机器检查、文件哈希和最终质量门。

## 用户确认包与内部阶段

| 用户确认包 | 可见产物 | 写入的内部状态 |
|---|---|---|
| 启动信息（仅缺失时） | 画幅、平台、时长、素材、声音、历史参考与重复人物摘要 | `video-brief.md` |
| 内容方向 | 叙事契约、完整口播、真实素材联系表、三套风格 | `script`、`source-assets`、主题选择 |
| 声音（需要 TTS 时） | 三条同文案试听 | `voice-selection.json` |
| 高风险原素材（按需） | 原图联系表、人物/品牌身份锚点 | `assets` |
| 成片蓝图 | 低风险原素材联系表、人物档案、全量静态分镜、平台遮挡图与复用附件 | `assets`、`storyboard` |
| 动态证明（按需） | 高风险/首次语法/反复人物的 4—8 秒微样片 | 样片证据，不替代 `motion` |
| 最终预览 | 完整低清视频和联系表 | `motion` |

一个用户确认包可以写入多个审批账本阶段，但每个阶段独立绑定本阶段真实文件及 SHA-256。下载/安装、敏感素材和授权疑点不得被普通“继续”顺带批准。

## 口播与镜头

1. 先写一句核心价值，再用 `story-contract.json` 锁定开头承诺、核心张力、贯穿线索和结尾兑现。
2. 信息流短视频在 0—2 秒给出真实结果、反差、问题或操作证据；资料不支持冲突时不制造假冲突。
3. 工具类内容按“结果或问题 → 关键动作 → 结果证据”推进；完成态不能由设置页或预览页代替。
4. 每个旁白段只绑定一个镜头，每个镜头只增加一种信息职责，并记录与前后镜头的连续性锚点。
5. 默认每 2—4 秒出现一次有效视觉变化；连续真实操作可延长，但必须持续推进状态。
6. 最终旁白生成后回填实测时长和分段时间戳；声音变化后重新对齐字幕、镜头、预览和成片。

## A-roll、B-roll 与镜头接力

- 先确定声音主轴，再决定画面角色。`a-roll` 是叙事与人格/对象主轴；`b-roll` 是当前句子的证据、操作、概念解释或跳剪遮盖；`hybrid` 保留主轴同时展示证据；`graphic-led` 让图解本身承担主画面。
- 每个 B-roll 必须写出 `covers`、进入理由和返回策略。写不出它正在解释哪句话，就删除，不用无关图片填满时间。
- 素材按“用户真实素材 → 官方素材 → 已核验关键帧 → 已授权静态补图 → 可编辑代码动画 → 纯文字/保留主轴”补缺。没有开工授权时不生成静态图；任何情况下都不调用视频生成模型。
- 转场默认硬切。只有对象、动作、方向或形状能够连续时才使用匹配剪辑；只有因果或步骤之间确有缺口时才增加图形桥接。
- 既有音视频先做词级转写，再把声音主轴、素材入点、A/B-roll、画面位置、转场和 `covers` 统一写进 EDL。节拍只能吸附未锁定切点，不能切词、改变总时长或覆盖语义完成点。

详细规则见 `roll-and-transition-system.md` 和 `editing-system.md`。

## 失效传播

上游变化只使实际依赖它的内容失效：

- 口播文字变化：受影响的音频时间轴、镜头和预览；
- 声音或语速变化：音频、字幕时间轴、镜头时长和预览；
- 素材变化：该素材审批、相关镜头、隐私复核和预览；
- 主题变化：版式、分镜和预览；
- 单镜头修改：该镜头局部预览和完整低清预览。

未变化的素材授权、声音、主题和无关镜头继续有效。

## 成片质量

- 成片继承已批准分镜的构图骨架，不把精排分镜换成原始录屏轮播。
- 平台风险词和禁用词覆盖口播、字幕、画面文字、封面和发布文案。
- 人物、Logo、产品截图和完成结果语义正确；真实证据可用时不用近似生成图替代。
- 完整联系表按原生分辨率检查事实、隐私、空白、裁切、字幕、人物动作、镜头连续性和主题漂移。
- 本地输出、上传、平台草稿、发布成功和真实用户效果分别记录，不互相冒充。
