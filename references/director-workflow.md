# 从口播到可执行分镜

## 先确定观众最后会明白什么

读完整稿，写这条片子给谁看、观众卡在哪里、看完能说明什么、哪一个对象或任务贯穿全片。例如“能说清谁派工、资料交给谁、结果由谁采用”，比“了解协作”更容易检查。

确定稿逐字保留。事实矛盾或时长问题标出具体位置，未获修改授权前不自行删句。视觉不能创造原稿和证据没有的主张。

## 先盘点，再选表现

新库的准备、许可与接入路线见 [动效库准备与选择](motion-library-selection.md)。

只读项目、用户已授权的素材目录与现有实现清单，记录实际可用内容：

- 已有画面及适用片段；未找到的外部视觉可以列为待搜。
- 已有开源动效的库、版本、许可、实现文件、入口、参数和执行/渲染证据。仅有网址、宣传演示或源码不等于当前可调用。没有合适实现，不把效果写入分镜，也不先开发一套再声称原本已有。
- 已有本地声音的真实文件、哈希、用途、可用区间与权利。区分正式旁白、参考音色、音效、环境声和配乐；有其中一种不能推定其他种类齐全。
- 已确认的画幅、风格、人物、声音偏好。引用已有档案；未知值标待定，不推测，也不另建全局偏好表。

用户明确授权准备新开源库时，先独立完成下载、接入与可用性核验，有真实实现和证据后加入目录，再开始选用。准备库与导演选择分开；下载到文件不等于运行可用。

导演只能从已核验实现中选择动效，从已有本地文件中选择音效、环境声和配乐。没有合适动效就用已有简单呈现、静态图或直接切换；没有合适音效/配乐就用 none。静态和无声可以是规划选择。规划通过不等于原有整片动态质量门禁通过；进入制作前，若静态方案不满足该门禁，应改用已有实现或合适的实景动作重新设计受影响镜头，不能补写不存在的效果。正式旁白尚未生成时，只写计划与估时，不冒充已经听过或测过。

逐镜按 [按内容分配效果](motion-system.md#按内容分配效果) 决定是否采用动效。目录大小不是使用配额；导演安排表达，剪辑师复核相邻镜头的重复、注意力和结果停留。

## 制作顺序与分工

1. 锁定原稿，写观众所得与贯穿线索，完成上述盘点。
2. **导演逐镜规划全片。** 每镜确定观看任务、画面组合、素材需求、景别、固定/运动理由、背景、前后状态和与下一镜的关系。已有实现才能承担动效；视觉素材可待搜。
3. **剪辑师逐镜安排。** 顺着导演镜头检查切点、共同对象、字幕分组、结果停留、已有声音的开始/停止和旁白避让；写在同一份分镜中。此时用估时，不另建时间轴。
4. 校验原文覆盖和资源可用性，导出完整可读分镜。已有授权直接复用，新选择集中呈现。**仅要求先交分镜时，到此停。** 不先找图、生成媒体或要求未进入执行阶段的声音配置批准。
5. 按分镜准备待搜的视觉材料，核查来源、许可、画面质量和可用片段。实际素材改变叙事时修改受影响镜头，不另起计划。
6. 素材准备后，按原有授权路线生成或读取正式旁白；已有授权本地 TTS 继续沿用，详见 `audio-system.md`。本地文件限制针对音效、环境声和配乐，不取消口播配音流程。按正式旁白的实测时间回填 EDL、字幕和事件。
7. 将原分镜推进到 ready，再制作镜头、合成样片与完整预览。检查真实输出后沿用原审批流程；局部样片不能替代全片审看。

只研究或升级 Skill 时不进入项目制作。

## 怎样把文字拆成画面

按意义切镜，不按句号、字数或固定秒数机械切。一个口播段可拆多个镜头，每镜引用一段连续原文；按顺序拼回去仍是确定稿。一镜一个主要观看任务，支持元素为这件事服务。

| 观众要理解什么 | 画面组织 | 可执行性要求 |
|---|---|---|
| 环境、人物动作、问题发生 | 相关实景，动作完整；必要时静态标注 | 缺画面可待搜，不能冒充已经看见 |
| 产品怎么操作、输出是什么 | 真实截图、录屏或验证结果，围绕目标取景 | 不用生成 UI 或别的产品当证据 |
| 人物、物件、场景关系 | 已有照片、合适素材或获准静态补图 | 找不到动作素材时，可用静态关系和旁白解释 |
| 先后、依赖、分工、信息流 | 稳定角色位置、方向明确的关系图 | 已有动效可用才逐步交接；否则用可读静态图/分镜直接切换 |
| 层次、容器、共享与隔离 | 必要时平面分区或 2.5D 分层 | 没有可用立体实现就用平面，不承诺开发 |
| 选择、对比、判断依据 | 同尺度对照、实际证据、结果停留 | 不以装饰性数字代替依据 |

素材类型不必平均分配。抽象权限关系可以直接用静态图，不必先塞一段办公室空镜。

## 每镜交给后续制作什么

逐镜写入 `shot-readiness.json`；字段见 `director-plan-contract.md`。导演写具体画面，剪辑师写怎样接、何时读、何时响：

- **原文与估时**：准确引用，估时为暂定；真实旁白到位后再测。
- **观众所得与构图**：看完能说清什么；主体和字幕放哪里；先看哪一处。
- **素材需求**：对象、动作、景别、连续可用长度、排除条件、搜索词、找不到的替代。例：“手在两张方案纸中选一张，俯拍，内容无个人信息，完整选择动作；找不到则用两方案静态对照”。
- **背景**：明确固定底色/场景或已有背景动效；强度、作用和跨镜延续。固定时写原因。
- **运镜与动作**：真实素材动作与程序动效分开说；程序效果必须引用已核验实例，不能只写“资料飞入”“立体展开”。
- **衔接与节奏**：`transition_reason` 说明本镜怎样接下一镜，哪句话后切，下一镜接住什么；末镜给结果停留。硬切不需要特效，特效转场须有已有实现。
- **声音**：旁白沿用哪条已授权路线，正式文件尚未生成时如实标明；音效/环境声/配乐引用已有本地文件，写触发、停止、尾音和避让。没有就明确 none。
- **字幕**：原文自然分组，按实测口播定时；固定独立安全区，不跟随镜头缩放。标题、图中标签与字幕分工，避免同一句堆三遍。

可读分镜采用全片总览与逐镜短列表。首屏回答预计多长、多少镜、还缺哪些视觉；随后能看到完整画面、衔接、字幕和声音。技术编号与哈希保留追溯，不用宽表堆十几栏。修改 JSON 后重导，不手工维护第二份。

## 剪辑师怎样检查连续性

先连续读三镜，确认每次切换新增什么信息。2—4 秒是节奏检查提醒，不是强制切镜；真实动作、比较和阅读可以停留更久。结果出现后留出读懂时间，不能一完成就切走。

照片或静态图可以固定。已有可用运镜才安排局部推进；人物换图检查脸部位置、比例与视线。跨镜共同对象在原 EDL 转场备注记录位置、比例、方向；需要连续运动时核对速度，普通硬切不用强求无缝。

出现编号时同步给出当前名称，比较结束保留参照。背景和字幕作为稳定参照；背景运动只有在承担明确职责且已有实现时采用。声音提前或延后必须有实际素材与清楚目的，切镜不切断词句。

## 关系图与立体表达

需要空间结构时读 `spatial-mechanism-explainers.md`。先定义角色、资料、任务状态和读写权限。既有动作可用时，同一事件驱动对象、标签和声音；资料到达后才显示收到。静态方案则用编号、方向和前后状态图说明，不用文字暗示不存在的动态。

立体遮挡中文或关系时退回平面。机制图标明示意，不承诺真实后台实现。

## 实际审片

合成前检查：只看分镜能否认出主对象；本镜比上镜多讲清了什么；素材条件是否足够让另一人去找；动效与声音是否真实可用。删去无解释作用的装饰。

合成后分别记录技术检查、完整带声审看与观众理解结果。检查切点前后、动作中途、结果停留和手机尺寸。字段、像素变化或局部样片均不能证明全片讲清楚。用户批准只覆盖实际看过的版本与范围。
