# 已确认项目的制作路线

适用：用户已有确定稿、授权声音、历史成片或批准画面，要求继续制作或局部修改。这是已有流程的分支，不新增审批账本、品牌档案或状态文件。

## 开始就锁定来源

1. 读取用户指定的唯一母稿、当前主题、声音配置和本次人物要求，记录实际文件与 SHA-256。当前明确要求优先于历史偏好。
2. 在已有 brief 和审批账本中引用真实确认记录。已批准的稿件不重写，已有声音不重新选，已有视觉系统不重做 A/B/C。使用 `selected_option=user-specified` 表达指定视觉系统。
3. 若旧手动稿与最近确认冲突，只核对冲突段。不要以修改时间最新代替用户明确确认，也不能把旧版本重新覆盖进母稿。
4. 核对授权范围后继续制作。新的人物、声音、题材事实或明显视觉方向变化才需要新的决定；内部测字、修字幕和去遮挡由 Agent 完成，不重新要求选声或选择风格。旧批准只适用于未变化文件；修改后的预览和来源哈希仍按现有审批契约记录，不让改后文件继承“已经看过”的状态。

## 先检查最容易返工的地方

- 逐句写观众看见的对象、动作、结果。身份和场景用相关真实素材；成本、替换与风险用具体物件表现；关系复杂处用机制图。允许同一镜融合，不设固定实景占比。
- 代表样片覆盖本片关键的“实景→机制→结果”交接，检查固定字幕层与声音。漂亮开头不能替全片混合方式背书。
- 用最终字体、最终运行时和实际文稿生成字形样张；检查缺字和真实行宽。登记具体 family/face，不只登记字体文件名。
- 字幕按完整意思分组，最多两行；字幕位置不随镜头转场。所有场景读取同一组位置与行宽参数。

## 只重做受影响部分

| 用户修改 | 重做 | 保留 |
|---|---|---|
| 一小段口播 | 该段 TTS、拼接边界与后续时间偏移 | 其他段音频与固定音色 |
| 局部文字、字体或遮挡 | 相关帧、转场中间帧和阅读窗口 | 旁白、其他画面与视觉方向 |
| 一张素材 | 对应授权、镜头和衔接 | 无关素材与口播 |

由最终音频派生字幕、EDL 与镜头时间；不手工维护第二条时间轴。段落复用用哈希核对，重新拼接需听接缝。用户只改稿件一段，不重生成全部声音。

## 渲染与证据

- 逐镜表、EDL、运动计划随镜头实现同步生成，先跑相应检查，再批量渲染；不要等全片导出后手填整套契约。
- 预览与母版共用一套原生坐标和帧函数，只改缩放或编码质量。已有质检报告记录渲染器、场景、口播、字幕、主题与素材哈希，不新建另一套状态。
- 实际 MP4 抽帧覆盖动作前、结果成立、阅读停留和转场中间。替换文字不能重叠，印章不能遮标题。
- 原始机器运动审计与人工覆盖契约分开保存。检查失败如实保留；密度比例低只是待检查信号，不能直接等同于空白，也不能删除失败来过检。
- “允许继续制作”“用户看过样片”“用户看过完整成片”是不同证据。不得把制作授权写成观看记录。抽帧检查也不能称为连续带声审片。

## 本次结束后

记录问题、原因、修复和验证范围。通用实现缺陷修进公开 Skill；个人声音、品牌、人物、本机路径与作品审查证据只留私有项目。单篇视觉认可不能证明传播效果，也不自动改掉所有未来视频的正式模板。
