# 把外部方法变成自己的视频语言

适用于已有个人或品牌风格，需要改善画面、镜头衔接和字幕的项目。先读当前用户选择和获准的历史成片。公开 Skill 保存制作方法；品牌、声音及私人素材留在 Skill 外。不要为了借鉴工具重选已确认的配色、声音或稿件。

## 风格先于效果库

从 `assets/creator-style-profile-template.json` 建立 Skill 外的风格档案。用户指定的品牌档案是唯一来源；项目记录源路径、哈希和本次覆盖。档案不能代替现有 `video-style-theme.json`、旁白契约或审批账本。已有同类档案时补充字段，不另建互相冲突的默认。

档案只记录有实际作用的几项：

- **识别**：已确认主题、字体、强调色、声音来源、人物是否出镜。人物出镜与品牌身份分开；有 IP 形象不等于每条视频必须放人物。
- **说话与叙事**：开头给什么，怎样用具体例子解释，结尾交给观众什么判断。稿件已确认时只安排画面，不重写文字。
- **素材与构图**：哪类证据优先，常用主对象、景别与对照方式。不能用固定的素材比例逼迫填入无关画面。
- **动作与节奏**：少量可反复使用的镜头动作，阅读与强调的停留方式，允许的声音提示。
- **禁用与实验**：用户否定的处理写成禁用；新镜头语言保持实验状态，未看片通过不能写“已验证风格”。

用户授权跨项目复用时，工作区规则只指向这一份档案。公开 Skill 只提交空模板、读取规范和通用检查，不提交品牌私有目录、参考人声、人物或项目路径。

## 先画对象，再排镜头

逐段填写 `visual-direction-plan.json`：`subject` 是观众看的具体对象；`material` 是真实素材或明确标注的示意；`action` 是当前旁白触发的动作；`result` 是动作后观众看懂的变化；`covers` 是本镜头解释的原话。

人物新闻优先相关人物或事件出处；交易优先钱、商品、价签、票据、交付；操作优先真实界面；关系复杂时才补机制图。概念道具可以用本地代码绘制，但不能做成似真的官方账单、经营数字或事件证据。

一镜一个注意中心。画面内的标题、字幕、背景只承担辅助职责。照片推进应露出更具体的目标；没有新信息的整页来回缩放不算一次镜头变化。

## 镜头怎么连

1. **保持一个共同对象。** 上镜价签停在成本，下镜同位置出现账单，观众知道仍在谈这笔交易。记录连接对象与前后状态。匹配剪辑要对齐对象中心、尺寸和方向；正在移动时承接速度，不能在切点停住再重新入场。
2. **动作有方向和结果。** 请求向中转入口送出，答案沿明确方向返回；不能让箭头只为了好看在不同方向飞。
3. **推进到新信息。** 从包装全貌到内部标签，再看到交付物。连续运镜使用同一场景坐标和取景变换，中途保持可识别的位置参照。推近是为了读到细节；结果出现后留下阅读时间。
4. **让对象遮挡完成交接。** 账单或包装经过画面时带出下一场景，可做短遮罩转场。遮挡前后要有语义关系，不使用随机几何擦除。
5. **证据镜头短插入、读完再走。** 页面先定位到当前原话，必要时返回原主对象。不要让整页小字快速滑过。
6. **旁白连续，声音有因果。** 切镜不切词。声效跟可见的收款、落章、打开、关闭等动作；出现时压低于人声。没有对应动作就不放音效。
7. **留下理解时间。** 结果停住可用于比较和读字。镜头内无需每秒运动；不得为通过像素变化检测添加漂浮和抖动。长时间无变化须记录 `hold_reason`，检查真实阅读需求。
8. **硬切也要设计。** 观点转折可直接切换对象或景别；记录为什么此时换。预排连续三镜的关注位置，避免视线无缘由地跨屏追逐。禁止把所有镜头统一淡入淡出，也不要求每次切换都有特效。

相邻镜头逐一记录 `from`、`to`、`type`、`anchor`、`reason`、`duration_seconds`、`audio`。常见转场可先试 0.15—0.5 秒；没有动作需要时硬切为 0 秒。不为转场改动旁白时间。字幕在独立屏幕坐标层保持稳定，不跟着推镜、旋转或飞出。

## 验收：看连续三镜

先做能代表新方法的连续样片，包括原配音、真实素材、字幕及声效，不能只给三张漂亮截图。至少检查：

- 关掉声音后，能否看出对象和发生的变化？
- 只听声音时，画面是否准确接住当前一句，而非提前给下一句背书？
- 连看三镜是否知道为什么从这里切到那里？转场结束后的结果是否读得完？
- 字幕是否完整、居中、稳定？缩小到实际预览尺寸还能否阅读？
- 是否沿用本账号确认的识别？是否误把参考项目的终端、主题色或角色直接搬来？

运行 `scripts/validate_visual_direction.py <计划.json>` 检查时间连续、必要字段、素材路径与逐镜桥接覆盖。它会提醒同构布局和需要人工检查的长镜头，不凭空判断画面吸引力。先查切点前、中、后三帧，再看连续三镜；改动一个切点时只复核受影响的相邻镜头。最终仍须查看实际视频；技术通过、样片好看和用户确认是三个不同状态。
