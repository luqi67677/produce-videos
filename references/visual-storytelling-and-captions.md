# 具体画面与可读字幕

适用于资讯、商业拆解、知识讲解，尤其是用户反馈“像线框图”“像 PPT”“画面空”“字幕太碎”的返工。它补充现有主题、分镜和声音规则，不另建 Skill，不更换已批准的稿件、音色或画幅。

外部方法怎样变成自己的风格、八条连续镜头规则与对应检查，见 `directing-methods-and-creator-style.md`。

## 先找每段值得看的对象

分镜先写清“观众在看什么”和“画面发生什么”，再选择版式。人物报道看对应人物及有关证据，交易看商品、钱、账单与交付，操作看真实界面，因果关系才用机制图。不能把所有段落直接翻译成“标题＋文字框＋箭头”。

- 有参考成片时，实际查看代表帧和连续片段，记录主对象、构图切换和字幕阅读单位。不能只读工程、文件名或模板名称就声称看过效果。
- 已选主题约束字体、颜色与画面组织；不要求把真实照片、实物或录屏都改画成线框。真实素材内部的自然背景和光影不属于合成装饰阴影。
- 镜头表给出具体素材、`covers` 原文、画面动作、观众由此看懂的变化。素材缺失时标注待补，不用写着素材名称的空卡冒充完成。
- 连续多个镜头只有相同的文字卡、箭头和数字时，检查是否漏掉原文中的具体对象、证据和结果。专业流程教学可以连续使用图解，不为凑比例插入无关素材。
- 公众人物照片只用于与该人物有关的叙述。不能把人物照片放到泛指欺诈、跑路或违法的镜头中，造成原文没有的指控。示意账单与道具金额不得冒充真实经营数据。

## 动画要改变观众看到的内容

优先选与语义吻合的少量动作，不把效果库中的所有动效堆进一条片。

| 讲解任务 | 可采用的画面处理 |
| --- | --- |
| 人物或事件入场 | 照片裁切与姓名锁定；转到有关页面的具体证据区域 |
| 钱怎样赚到 | 具体账单、价签、零钱或收款记录；成本与收款分开揭示 |
| 商品或模型被替换 | 同一物件、标签或包装发生替换；结果在同一镜头中显现 |
| 缓存或重复计费 | 同一段输入被复用；先看到实际成本，再看到对外账单 |
| 数量和差距 | 保持坐标与比较对象稳定，让对应数字或数量发生变化 |
| 服务关闭或风险 | 可辨识的操作状态发生改变；异常出现时再配短提示音 |

照片推进、局部放大、遮罩揭示、匹配切换、物件拆合和分屏比较，都可在本地完成。对同一整页反复缩放，不构成新的信息。声效对应可见动作，不能每次切镜都加一声；旁白始终清楚。

用户要求免费且不用生成 API 时，锁定已有音频、合法可用素材及本地合成。不要把免费额度、试用账号或需要另付费的生成演示算成免费本地路线。浏览、下载公开素材与调用生成 API 分开记录；不替用户注册服务或充值。

## 展示字幕与识别切片分开

识别结果用于对齐声音，不直接决定字幕显示单位。

- 先按完整意思合并展示字幕。逗号不是强制切点，“比如”“充钱”“高价卖”等依附前后的短词不单独闪现。
- 保留原文字与原词时间。合并只改变展示窗口，不改旁白，不用字数推算替换已有实测时间。
- 竖屏讲解默认在下方可用安全区内水平居中，最多两行。避开平台右侧按钮与底部文案，按安全区的中心定位，不把文字容器固定贴到最左边。
- 常见阅读单位约 2—4 秒。语义完整的短问句、强调词可以更短；完整长句可以更长。不能机械地凑时长，不能把下一句提前显示到当前镜头。
- 1080×1440 中文字幕可从 38—44 px 起调，按真实字体测量换行，并检查 540×720 预览。字号取决于目标设备和画面，不直接继承旧模板的小字号。
- 默认整组稳定显示。逐字点亮、卡拉 OK 和弹跳仅在用户选择这种字幕语言时启用。
- 检查原文拼接一致、时间递增无重叠、短碎片、两行上限和平台遮挡。中文换行优先选标点与语义边界，允许两行不等长，不把“真正”“麻烦”等完整词拆开。英文品牌词不从中间断开。

## 返工如何验收

原先被评价为线框图的片子，先做能体现新方法的连续样段：真实主对象、可见的动作结果、完整字幕和原配音同时出现。静态拼图只能说明构图，不能证明动效或字幕阅读体验。

检查连续三镜是否在讲不同的事情、具体素材是否可辨认、字幕是否读得完。文件可播放、画面像素有变化、技术预检通过，均不等于用户认可创意质量。

## 方法参考

本页为独立整理的制作规则，未复制第三方程序、配方正文或素材。公开项目在 2026-10-14 核验；采用前仍按各自许可证与依赖条件检查。

- [HyperFrames](https://github.com/heygen-com/hyperframes)：本地 HTML 时间线与素材合成。
- [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)：按镜头作用浏览动作示例，将素材、动作、节奏一起编排。
- [OpenMontage](https://github.com/calesthio/OpenMontage)：检查连续同构图、文字过载和无叙事作用的运动；区分素材剪辑与付费生成路径。
- [Remotion 字幕分组 API](https://www.remotion.dev/docs/captions/create-tiktok-style-captions)：将转写时间与展示分组分开。中文按语义处理，不直接套英语空格分组。
