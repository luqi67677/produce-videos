# 从分镜阶段进入剪辑工作台

版本：V0.3，实验接入。运行时为 Hyperframes 0.8.164 + `pv-sync-cut-1`，Node.js 22+。本版增加中文界面与本地品牌配置，保留全轨同步剪切；HTML 与正式 EDL 的自动同步、最终导出镜头缓存仍未实现。

## 什么时候打开

用户要求工作台、在界面里改字幕/画面/声音、手动切开或删除片段，或项目偏好已指定工作台时，新项目从第一版画面稿就用工作台交付中间预览。沿用同一个工程进入配音、字幕和审片阶段。已有项目先检查当前实现；不能为了打开编辑器重建整片或丢掉用户修改。

没有配音时允许 `planning/estimated` 画面稿。界面说明这是估时预览，音频可以缺失，不能虚构配音或把估时写成实测。用户能在浏览器里查看和编辑，无须先编码完整 MP4。最终成片仍须导出并通过原有检查。

## 工程与四种操作

- 看片：根 `index.html` 合成，播放、暂停、定位镜头；同目录 `STORYBOARD.md` 列出镜头职责和状态。
- 画面：一镜一个 `compositions/<scene_id>.html` 子合成。子合成使用 `<template>`，内部包含根容器、样式与暂停的 GSAP 时间线；以实际 Hyperframes 版本的模板和 lint 为准。保持稳定元素 ID，便于只替换一个对象或镜头。
- 字幕：根合成只保留一个字幕层。第一版用有稳定 ID、起止时间的独立文本元素，直接编辑文字、字号和位置。不要把画面文字和字幕混为同一对象。
- 声音：旁白、音效和配乐分别占轨，引用已有授权文件；支持选中音频调音量和试听。没有声音的画面稿不阻止打开。

这四项使用上游 Studio 的画布、属性面板和轨道。界面入口已使用中文，仍沿用原生面板与轨道结构。若使用原生 `.caption-group`，先读官方字幕说明：部分分组、时间与动画编辑不会跨刷新保留；不能以界面显示变化代替保存成功。第一版普通文本字幕也不等于词级对齐编辑器。

为镜头、素材与字幕保留 `scene_id`、`clip_id`、`asset_id`、字幕 ID；可在元素上使用 `data-pv-scene` 和 `data-pv-role` 标记归属。稳定 ID 不等于已实现 EDL 字段映射。`shot-readiness.json` 与 EDL 继续保留原 schema，不自造另一套审批状态。

## 手动切开、剪掉和删除

交付工作台时必须保留可操作的时间轴，并指出下面的入口。用户可以直接完成这些编辑，不必先让 AI 代为修改。

- 切开主画面：选中主画面轨道的片段，把播放头移到切点，点击时间轴工具栏的 “在播放头处分割”。本机已通过此入口验证拆分。右键菜单显示可用的 “分割” 时也可使用；普通 div 或嵌套场景的右键菜单不一定提供此项。要剪掉中间一段，在该段起点和终点各切一次，再选中中段，右键选择 “删除”。
- 删除整镜或片段：时间轴默认显示“全轨同步”。选中目标片段，右键 “删除”，会从所有轨道删除它占用的时间区间。画面、普通定时字幕、旁白、音效和配乐一起裁切、前移，根合成时长同步缩短。隐藏或静音的轨道也参与。
- 剪掉中段：在区间起点和终点分别 “在播放头处分割”，选中中段后 “删除”。跨过这个区间的媒体会分段并保留源内偏移，后半段从剪切后的原素材位置继续播放。
- 只删一个声音或字幕：先点击“全轨同步”切换为“仅删所选”，再选中片段 “删除”。此时保留其他轨道和全片时长。原素材文件保留在资源目录。
- 撤销：全轨剪切记录为一次编辑。一次 “撤销” 恢复本次剪切的全部轨道、源内偏移和总时长；“重做” 重做。拆分动作各有自己的撤销记录。

多选片段按时间区间的并集处理，重叠区间不会重复扣时。一次操作在同一场景文件内计算完毕后统一保存；遇到版本冲突或无法可靠裁切的结构，整次拒绝，不保存一部分。进入子场景时间线可剪该子场景；主时间线剪子场景实例时，只改实例的播放窗口，不重写被复用的子文件。

本版支持固定数值时间和恒定播放速率。原生词级字幕、引用式起点、复杂循环/计算型动画及尚未适配的音频自动化需先适配，不能静默跳过；遇到拒绝提示保留文件，核对原因后再操作。删除整片为零时长工程暂不支持。

## 打开与编辑

1. 读取当前项目、已确认文案和偏好，生成或复用符合上游规范的原生工程。使用本地资源，运行 Hyperframes lint。不要复制本机音色、个人形象、私人路径进公开 Skill。
2. 按 `workbench-adapter.md` 运行 `doctor`；运行时缺失时在当前项目或用户的工具目录准备锁定版本，安装并核验 `pv-sync-cut-1`，记录实际 CLI 路径。`open` 还会检查正在运行的服务，拒绝复用旧进程。不要静默使用未验证最新版。
3. 首次打开前运行 `snapshot`。运行 `open` 后使用实际返回的 `studioUrl`，在可用浏览器打开并确认有画面、正确时长和轨道。CLI 成功不等于界面可用。
4. 用户直接编辑时等待保存。AI 动手前先 `check`，再读发生变化的完整实际源文件；`inspect` 的截断文本只能用于定位。先保留最新用户修改，再作窄修改，不能用旧生成结果覆盖整页。用户手动删除的镜头、声音或片段也属于必须保留的修改；不能因为旧 EDL 仍有记录就重新生成或恢复它们。
5. 能用工作台提供的 AI 接口时，先读取当前选中对象并 inspect，再用稳定 handle 修改指定对象。依据接口的 saved/verified 状态、实际文件差异及刷新回读判断成功；dispatched 只能表示已发送。接口不可用时窄改实际源文件并看热更新结果。
6. 改动后重新看相关镜头与相邻切点，核对文件差异，保留上一可用版本。确认已接收当前变化后才 `snapshot --replace-baseline`；该基线不能充当用户批准。

## 时间与确认仍沿用原契约

HTML 保存画面表现；旁白文件与实测信息沿用声音契约；正式剪辑时间仍以核对后的 EDL 为准。用户在时间轴拖动、拆分、删除、裁切或调整声音后，AI 必须把变化逐项核对回 EDL 与逐镜表，再运行同步校验。当前适配器只发现文件变化，不自动完成这一步，禁止输出“已自动同步”。

UI 已保存的文件与旧 EDL 冲突时，保留用户最新编辑，记录待核对差异。禁止按旧 EDL 恢复已删镜头、声音或中段。正式导出前，将保留片段和删除结果准确写回原契约；无法映射时保持待核对状态，不能静默恢复旧内容。

拆分后逐项核对：

- 每个保留片段的 `clip_id` 与 DOM ID 唯一，保留来源 `scene_id`、`asset_id` 和素材路径；多个片段引用同一子合成不等于重复片段，不能自动合并。
- 每段的时间轴起点、时长和源内起点对应当前保存结果。动画或嵌套子合成用 `data-playback-start` 保存局部播放偏移；音频等媒体片段用 `data-media-start` 保存媒体内起点。两者不能混用，必须连同挂载时长核对，不能让右段从源头重播，也不能假设新 DOM ID 已自动映射为 EDL ID。
- 删去中段后，核对左右两段的源内容仍分别对应原保留区间，检查相邻切点、字幕、声音与总时长。确认处于“全轨同步”模式；“仅删所选”不会改变其他轨道。

修改了台词含义或旁白文字时，先确认是否也改配音；仅改显示字幕不能冒充口播已更新。字幕、音效或画面发生变化时，受影响审批按现有文件哈希失效。正式导出前仍要求 `ready/measured`、真实配音绑定、`validate_director_plan.py --require-ready`、`validate_timeline_sync.py` 和原 render gate。实时预览不替代导出审片与平台实测。

## 哪些重做可以省

改画面、字幕样式、音量后直接在 Studio 预览，省去每轮完整视频编码。优先只改相关镜头文件，不重新生成无关素材和配音。

本版尚未实现最终导出的镜头缓存。最终 MP4 仍可能整片编码。Hyperframes 的 `--resume` 是失败续跑机制，不能据此宣称修改镜头后自动复用全部其他镜头。未来缓存需要覆盖字体、素材、字幕、声音、全局主题和相邻转场依赖，另行实现和验证。

## 中文与本地品牌

工作台菜单、操作说明和属性标签使用简体中文。用户字幕、素材文件名、工程路径与代码内容保留原文，不做全页面文本替换。界面品牌名称和文字标志读取包外风格档案的 `editing_workbench.brand.name` 与 `mark`。未配置时使用“视频制作”。启动前用补丁安装器的 `--brand-profile` 更新；不要把私人档案、声音或本机路径复制进公开 Skill。底层运行时的开源授权与版权说明继续保留。


### 时间线与图层名称

操作界面中文化之外，新工程也要给可编辑元素设置中文显示名。使用 `data-timeline-label`，例如：

```html
<div id="s03-title" data-timeline-label="镜头 03 · 标题">确认以后，再导出</div>
<audio id="voice-03" data-timeline-label="镜头 03 · 旁白" src="assets/voice-03.wav"></audio>
```

中文补丁让时间线、图层列表和属性标题优先显示 `data-timeline-label`，其次使用 `data-label`；没有显式名称时才沿用原来的自动名称。素材类型与自动轨道名使用中文。内部 ID、选择器、文件名和用户素材内容保持原值。已有用户名称不覆盖；需要改名时，只改显示属性，不重建场景或还原被删除的片段。验收要查看实际时间线和图层列表，不能只检查菜单。
