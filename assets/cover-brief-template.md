## 规则

- 封面继承已锁定的全片主题，不再次选择配色。
- 每条视频都交付独立封面，不直接把视频首帧当封面。
- 契约 schema 1.1 必须填写 `content_mode`。旧 schema 1.0 未填写模式时，仍按 Skill 推广校验；未知模式不能通过。
- general 封面以内容主标题为主，可不加副标题或 Skill 名称。有副标题时，须与主标题分工，不重复内容，并检查层级。
- skill-promotion 封面须有主标题、副标题和 Skill 名称；主标题先说目标用户/场景与痛点或结果，副标题说明 Skill 的差异化能力，两者不得重复。
- 仅 skill-promotion 强制显示 Skill 名称，并保持原始大小写，不用全局大写或缩成看不清的角标。
- 两种模式都须保留主标题、已批准主题与真实输出；有主视觉素材时核查授权，原尺寸和缩略图审查及用户确认不能省略。
- 标题在目标平台的缩略图尺寸下仍应可读。
- 用户确认的标题必须逐字保留；不能为了缩略图、信息减法或模板适配擅自缩短和改写。
- 中文或中英混排主标题使用中文优先字体；品牌词保持原始大小写，禁止全局大写转换。
- 有真实主视觉时只选一个，并让它足够大；不在封面上并列多个互相竞争的小截图。
- 使用人物或角色时，只能使用用户提供或明确授权的资产，并检查肢体、遮挡和裁切。
- 人物动作和服装必须服务封面信息；禁止任意跪坐、促销手势、复制正文姿势或与职业/内容场景不匹配的造型。
- 没有已授权人物时，使用真实产品、结果证据或用户提供的品牌素材作为主视觉，不生成发布者个人形象。
- 最终封面额外输出缩略图进行可读性检查。
